# Design & Review Skills Plan

_Last updated: 2026-08-11_

Tracks which Claude Code skills apply to this project and the order they're being run in. Two buckets: **audit-now** (run once, top to bottom, against the whole app) and **contextual** (invoked on-demand whenever work touches that area — not a one-time pass).

## Audit-now (run in this order)

1. **react-component-structure** — structural check first (SRP file layout: types/consts/styles/utils split). Fixing structure after visual polish means redoing the polish, so this goes first.
2. **redesign-existing-projects** — design audit: fonts, color palette, layout patterns, generic "AI slop" tells (this was already in progress before being interrupted).
3. **better-interface** (full review mode) — cross-discipline pass coordinating `better-accessibility`, `better-layout`, `better-typography`, `better-colors`, `better-ui`, `better-writing`. Runs after the design audit to catch what a pure visual pass misses (focus states, aria, copy tone).
4. **dataviz** — only touches the Recharts-based dashboard bento cards; run when those components are in scope.

## Contextual (invoked when the relevant area is touched, not as a blanket pass)

- **clerk-nextjs-patterns** — Clerk middleware / Server Actions changes.
- **mercadopago:mp-integration-expert** (routes to `mp-review` / `mp-webhooks` / `mp-test-cards`) — Mercado Pago integration work.
- **neon:neon-postgres**, **neon:neon-postgres-branches** — Prisma/Neon schema or branching work.
- **vercel:nextjs**, **vercel:shadcn**, **vercel:deploy**, **vercel:env**, **vercel:vercel-cli** — deploy/env/shadcn-component work.
- **code-review**, **work-unit-commits**, **chained-pr**, **branch-pr**, **issue-creation**, **judgment-day** — applied during commit/PR steps.
- **run** — launch + screenshot the app to verify a change in the browser, not just via types/tests.
